# Real-Time-Weather-Dashboard
🌦️ Real-Time Weather Dashboard using Power BI &amp; Weather API  This project is a Real-Time Weather Dashboard built using Power BI and a Weather API to fetch live weather data. The dashboard provides up-to-date weather insights, helping users monitor current weather conditions through interactive visualizations and dynamic reports.
🚀 Features
Real-time weather data integration using Weather API
Interactive Power BI dashboard
Current temperature, humidity, wind speed, and atmospheric pressure tracking
Weather condition monitoring (Sunny, Cloudy, Rainy, etc.)
Dynamic visualizations and KPI cards
🛠️ Technologies Used
Power BI – Data visualization and dashboard creation
Weather API – Real-time weather data source
Power Query – Data extraction and transformation
DAX – Calculated measures and KPIs
